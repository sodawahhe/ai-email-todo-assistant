# 学术助手 v1.5 产品报告

**发布日期：** 2026-05-05
**主题：** 从「Sheet 打勾的 Todo」升级为「带仪表盘的游戏化任务系统」+「学生热议聚类」

---

## 这次解决了什么

### 用户的四个原始痛点

| # | 痛点 | 根因 | 修复方式 |
|---|------|------|---------|
| 1 | 私人 Google 账号假期里发出乱码简报 | 私人账号上残留的脚本副本和触发器自己在跑 | 用户在私人账号侧删除触发器（更干净） |
| 2 | 学生 Ed 帖污染 Todo，token 浪费严重 | `quickClassify` 检测到 Ed 邮件后仍 `needsAI: true`，每封都调 AI 提取「任务」 | Ed 通知邮件 `needsAI: false`；学生帖只存标题，不调 AI |
| 3 | 教育邮箱被 Ed 通知淹没 | Ed Discussion 默认开启邮件通知 | 用户关闭 Ed 设置中的邮件通知（不动用户邮件） |
| 4 | Sheet 里打勾太粗糙，简报里看不能直接完成 | 没有交互层 | Web App + 一键完成按钮 + 仪表盘 |

### 顺带满足的隐性需求

- 用户表达"不是个很自律的人，需要可视化或者游戏奖励" → **加入连胜、XP、进度条**
- 用户希望"大概浏览学生帖子然后提取重复最多的重要问题" → **学生 FAQ 聚类**

## 核心新功能

### 🏆 仪表盘 + 一键完成（最大改动）

**简报顶部新增进度卡**

```
┌─ 🏆 今日进度 ───────────────────┐
│ ▓▓▓▓▓▓▓░░░░░░░░░░ 43%           │
│  3/7    🔥5    ⭐30    14        │
│ 完成/总  连胜  今日XP  本周完成   │
│  [📊 打开实时仪表盘 →]          │
└─────────────────────────────────┘
```

**每个 Todo 旁的胶囊按钮**

- ✅完成 → 点击 → 浏览器打开确认页 → "今日进度 X/Y · XP +10 · 🔥 连胜 N 天" → Sheet Status 自动 = `已完成 Done`
- ⏭️忽略 → 点击 → 该任务下次简报不再出现
- 确认页底部有「↩️ 撤销」，点错可恢复

**独立 Web App 仪表盘**

- 加书签的 URL，随时打开看实时状态
- 按 48h / 本周 / 之后 / 无截止 分卡片展示
- 直接在页面上点方框打勾，即时划线 + toast 反馈
- 顶部进度条 + 4 项数据格

### 🔥 学生热议 FAQ 聚类

每天发简报时执行：

1. 读取过去 24h 学生帖标题（`Ed Student Posts` 表）
2. 按课程分组，每课最多 30 条标题
3. 1 次 AI 调用聚类 → "多人问的共同主题，至少 2 人问过"
4. 返回 Top 3-5 个主题，每个含课程、主题、人数、2 条示例

**简报里长这样：**

```
🔥 学生热议 / Student FAQs                3 个主题
─────────────────────────────────────────────
[FIT5197] Assignment 2 Q3 中位数怎么算    🟡 4 人问
  · How to compute median when n is odd?
  · Q3 part b — median calculation help

[FIT5145] Lab 6 Tableau 连接数据库报错     🟡 3 人问
  ...
```

**成本控制：**
- 学生帖 < 5 条时跳过（避免无意义调用）
- 每天就 1 次调用，输入 1-3K token，输出 ~500 token
- 月成本约 0.05 元（DeepSeek v4-flash）

### 🧑‍🏫 TA 帖现在和老师帖同等对待

之前的 v1.4 把 TA 帖归类为 `ta`，但既不调 AI、不进简报、不进 Todo——形同丢弃。

用户实际反馈："导师几乎不发帖，大部分都是 TA 在发通知"。

修复后 TA 帖：
- 调 AI 提取任务和 deadline
- 写入 Ed Posts 主表
- 进入 Todo 列表
- 简报里显示 🧑‍🏫 助教 标签

## 技术架构变化

### 新文件
- `09_StudentFAQ.gs` — FAQ 聚类逻辑（80 行）
- `10_WebApp.gs` — Web App 路由 + 动作处理 + 仪表盘渲染（130 行）
- `dashboard.html` — 仪表盘 UI 模板（230 行 HTML/CSS/JS）

### 新 Sheet
- `Ed Student Posts` — 仅存学生帖标题（postId / 时间 / 课程 / 标题），用于 FAQ 聚类
- `Stats` — 每日完成数 / 总数 / XP / 连胜天数

### 关键修改
- `02_GmailScanner.gs`：Ed 通知邮件 `needsAI: false`（这是 token 节省的最大单点）
- `06_EdDiscussion.gs`：学生帖标题分流到独立表；TA 帖纳入 AI 处理
- `04_SheetsWriter.gs`：`getRecentEdPosts()` 公告优先排序 + 限 6 条；新增 Stats 函数族
- `07_TodoList.gs`：TA 类型加入白名单；`buildTodoList()` 末尾写今日总数到 Stats
- `05_DigestEmail.gs`：顶部进度卡片 + Todo 一键按钮 + FAQ 区块
- `01_Main.gs`：`setupTriggers()` 自动生成 Web App token；`testSetup()` 加 Web App 检查

### 安全设计
- Web App 部署为「任何人可访问」（必须，否则邮件按钮无法匿名触发）
- URL 必须带 `token=<UUID>` 参数才接受请求，token 仅存于 Script Properties
- 撤销操作和完成操作走同一鉴权机制

## 成本对比

| 项目 | v1.4 | v1.5 |
|------|------|------|
| 每封 Ed 通知邮件 AI 调用 | ~1 次 | ❌ 不再调用 |
| 每天 Ed sync AI 调用 | 公告/讲师帖每条 1 次 | 同（公告/讲师/TA 每条 1 次） |
| 每天 FAQ 聚类 | 无 | ➕ 1 次 |
| 简报 token 体积 | 受 Ed 任务和误识别学生任务影响，膨胀严重 | 大幅缩减（学生帖不再变成虚假任务） |
| **预计月成本** | 实测远超 1.3 元 | 回到 ~1.5 元/月 |

净效果：节省的远比新增的多。

## 用户使用流程

### 首次部署后（一次性）
1. Apps Script 编辑器 → 部署 → 新部署 → Web 应用
2. 配置：执行身份"我"，谁可访问"任何人"
3. 复制部署 URL → 脚本属性新增 `WEBAPP_URL`
4. 跑 `setupTriggers()`（自动生成 token）
5. 跑 `testSetup()` 验证全绿

### 日常使用
- 早上 8:30 收简报 → 看进度卡 → 点 ✅完成 标记昨晚做完的事 → 看 🔥 连胜涨没涨
- 任意时刻打开仪表盘 URL → 看实时状态 → 直接勾选完成
- 看 🔥 学生热议区 → 知道大家都在卡哪一题，决定是否要研究

### 触发器仍然全自动
- 每 2 小时扫邮件
- 每 6 小时同步 Ed
- 每天 8:30 / 18:00 发简报
